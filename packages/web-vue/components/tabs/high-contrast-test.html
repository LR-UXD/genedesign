Tabs 组件高对比度测试

测试说明

此页面用于测试 Tabs 组件在高对比度模式下的显示效果。点击右上角按钮可以切换高对比度模式。

在高对比度模式下，应该能够清楚地看到：

  • Tab 标签的边框和背景
  • 当前活动标签的高亮显示
  • 焦点状态的明显指示
  • 悬停状态的视觉反馈
  • 禁用状态的灰色显示
  • 下划线指示器
  • 关闭按钮和添加按钮

改进要点

CSS 改进

  • ✅ 添加了 @media (prefers-contrast: high) 媒体查询
  • ✅ 添加了 @media (-ms-high-contrast: active) 支持 IE/Edge
  • ✅ 添加了 @media (forced-colors: active) 支持现代浏览器
  • ✅ 使用系统高对比度颜色: WindowText, Highlight, HighlightText, ButtonFace, GrayText
  • ✅ 确保所有交互状态都有明确的视觉反馈
  • ✅ 改进了焦点指示器的可见性

可访问性改进

  • ✅ 添加了 role="tablist" 到导航容器
  • ✅ 添加了 role="tab" 到每个标签
  • ✅ 添加了 role="tabpanel" 到内容面板
  • ✅ 添加了 aria-selected 属性
  • ✅ 添加了 aria-disabled 属性
  • ✅ 添加了 aria-hidden 属性
  • ✅ 添加了 aria-orientation 属性
  • ✅ 添加了 aria-label 和 aria-labelledby

技术实现

修改的文件：

  • packages/web-vue/components/tabs/style/index.less - 添加高对比度样式
  • packages/web-vue/components/tabs/tabs-tab.vue - 添加 ARIA 属性
  • packages/web-vue/components/tabs/tabs-nav.tsx - 添加 tablist 角色
  • packages/web-vue/components/tabs/tabs.tsx - 添加 tabpanel 角色
  • packages/web-vue/components/tabs/tab-pane.vue - 添加面板 ARIA 属性
